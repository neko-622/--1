注意事项
1.PCB文件打板前请仔细检查所有封装，塔吊扩展板的降压模块可以自行替换。
2.视觉和电控代码都是经过实机测试的，不会有重大bug，但是注意电机模式和零位！
4.机械开源仅供参考，因为SW模型导出制图文件后又进行了少量的修改，整体没有大问题，但是细节需要自行打磨，打印件同理。
5.机械打板之前仔细检查孔位，可能有理线孔位置略有偏差，实物电机替换为DM4310，孔位和高度均不一致，根据实际需求修改。
6.机械打板推荐使用玻纤，因为绝缘。碳板导电。
7.注意硬件接线，注意电机零位，谨慎测试，注意安全！
